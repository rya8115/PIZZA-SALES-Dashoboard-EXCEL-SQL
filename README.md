# PIZZA-SALES-Dashoboard-EXCEL-SQL
# 🍕 Pizza Sales Analysis

This project leveraged Excel and MySQL to analyze 21,350+ pizza orders, identifying that 35% of total sales occur during weekend peak hours (6–11 PM) to optimize staff scheduling and labor allocation. By pinpointing "Classic Large" pizzas as the primary revenue driver (28% of total sales; $817k), the analysis provided a data-backed framework for inventory prioritization and targeted promotions for underperforming menu items. To ensure 100% data integrity, all dashboard metrics—including 49,574 units sold and a $38.31 average order value—were cross-verified using MySQL queries, delivering accurate, actionable insights for strategic business growth.

# PIZZA-SALES-Dashoboard-EXCEL-SQL
# 🍕 Pizza Sales Analysis

This project presents an end-to-end analysis of a pizza restaurant's sales data spanning the entire year of 2015, comprising 48,620 transactions across 21,350 unique orders. Using Excel, the dataset was examined to uncover key business metrics such as total revenue of $817,860, an average order value of $38.31, and performance across 32 pizza varieties grouped into four categories — Classic, Veggie, Supreme, and Chicken. The analysis dives into size-wise revenue distribution (Large pizzas leading at 46%), identifies top performers like The Thai Chicken Pizza, and surfaces patterns in order timing and customer preferences — offering a comprehensive view of what drives sales in a fast-paced food service environment.
